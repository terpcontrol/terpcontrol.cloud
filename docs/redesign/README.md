# Redesign

[`C51-konzept.md`](C51-konzept.md) is the chosen design. Everything else here is the evidence behind it.

## The design

C51 — *Der Unterschied*. Every thing in the app is a *Ding* with one screen shape; that shape's body is
always a Vorher/Jetzt pair with the change named in one sentence; and a single slider, shared across
everything you walk to, decides what *Vorher* means. Set "Vorher = Freitag 14:02" once and the tent, a
plant, a socket, a target and a person each answer the same question against it.

Two disciplines hold it together: the picture *describes* a difference and never diagnoses it, while the
numbers may *prescribe* — but only for kit the app itself switches, with the rule that produced the advice
named alongside it.

## Research

Start with [`00-dossier.md`](00-dossier.md); it consolidates the rest and is the only file most readers
need. [`00-verified-notes.md`](00-verified-notes.md) holds facts established by reading this repo directly
and is the tie-breaker where a report and the code disagree.

The numbered reports are the raw material. `01`–`06` look outward (grow-diary platforms, nutrient feed
charts, social posting, competitor apps, club regulation, charting practice); `10`–`14` document what this
repo did before the redesign.

Claims carry provenance tags — `[VERIFIED]` and `[CODE]` were checked, `[INFERRED]` and `[UNVERIFIED]`
were not. Pricing, API tiers and platform policies were accurate when gathered and will drift; re-check a
number before acting on it.

## Mockups

[`mockups/konzepte.html`](mockups/konzepte.html) is the review page as it stood when C51 was chosen —
open it in a browser. The individual fragments beside it are the finalists and the three concepts C51 was
built from, kept so the choice can be re-examined rather than taken on trust.

Sixty concepts preceded these and were scored by ten critics standing for the user types the product
serves. Those documents were removed once the decision was made; the reasoning that survived them is in
the dossier and in C51 itself.

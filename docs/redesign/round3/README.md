# Round three — ten hybrids

Three concepts were picked out of the previous sixty, and these ten combine them:

- **C14** — the primary object is a pair of pictures with the difference named in one sentence. It
  describes differences; it never diagnoses them.
- **C36** — everything is a *Ding*, a named thing with a time, a body and named relations, and there is
  one way to look at any of them. Depth comes from walking a relation, never from switching a mode.
- **C11** — the shared-cursor slider: the film strip and the chart render from one playhead, and pausing
  unfolds everything known about that minute.

Each concept states what it takes from each source and, more importantly, what only exists because they
were combined. A concept that still makes sense with one source removed has not fused anything.

Two ideas recur because the combination produces them rather than because they were briefed. The first
is that the pair, the film and a single row are the same trace at one, two and n samples — so the three
sources stop being three features. The second is that a remedy which must point at something it can
change cannot be vague, which is how several of these end up with working advice where sixty earlier
concepts had none.

The mockups are the deliverable for this round; each concept is drawn across six situations, including
the three the earlier rounds handled worst — a real problem with a real remedy, the first day with
nothing to show, and an old device with one sensor.
